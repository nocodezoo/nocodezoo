## Rules

- Fill slots in order: mandatory items first (1–11), then fill remaining slots with any uncovered room type
- **Bedrooms: max 2** — never more, even if slots available
- **Bathrooms: max 2** — never more, even if slots available
- If a required category has multiple good photos, prefer the best-quality image
- Aerial/hero shots go first if available
