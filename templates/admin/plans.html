Note: Stripe Price IDs must be created manually in the Stripe Dashboard.
After creating a product and price in Stripe, set the Price ID in the STRIPE_PRICE_IDS environment variable on the VPS as a JSON object:
STRIPE_PRICE_IDS='{"Free": "price_xxx", "Pro": "price_yyy", "Enterprise": "price_zzz"}'

Then restart the user_api service: sudo systemctl restart vybord-user-api
