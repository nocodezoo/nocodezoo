Use the image-to-video tab/workflow in Wan2GP, upload a single still image, add a motion prompt, then click Generate.

Fastest way: use the Gradio web UI

Open the Wan2GP Gradio app in your browser.
Select Image-to-Video or I2V.
Upload your source image.
In the prompt box, enter something like:

Subtle cinematic camera motion, strong depth parallax, paradox 3D effect, slow Ken Burns zoom, gentle dolly zoom, aerial drone-like movement, smooth motion, high detail, realistic perspective

If available, adjust:
   Duration: start with 3–5 seconds
   Resolution: use a moderate setting first
   Seed: fixed if you want repeatable results
   CFG / Guidance: medium values usually work best
   Steps: higher = slower but often better quality
   Motion strength: moderate, so the image does not distort too much

Click Generate.
Download the .mp4 when it finishes.

If you want to use the Python script

Here is the practical workflow:

1. Install the client

pip install gradio_client

2. Save a local image

For example:

C:\videos\input.jpg

or

/home/you/input.jpg

3. Use a script like this

import os
import shutil
from gradio_client import Client, handle_file

SPACE_ID = "Wan-AI/Wan2.1-I2V"   # replace if your Space is different
IMAGE_PATH = "input.jpg"
OUTPUT_VIDEO = "wan2_result.mp4"

prompt = (
    "Subtle cinematic camera motion, strong depth parallax, paradox 3D effect, "
    "slow Ken Burns zoom, gentle dolly zoom, aerial drone-like movement, "
    "smooth motion, realistic perspective, high detail"
)

client = Client(SPACE_ID)

Optional: inspect the actual API first
client.view_api()

result = client.predict(
    handle_file(IMAGE_PATH),
    prompt,
    api_name="/predict"   # may need to change depending on the Space
)

print("Raw result:", result)

If result is a filepath, save it
if isinstance(result, str) and os.path.exists(result):
    shutil.copy(result, OUTPUT_VIDEO)
    print("Saved video to:", OUTPUT_VIDEO)
else:
    print("Generation finished, but inspect the returned object above.")

Important detail: view_api() matters

Different Gradio apps often use different parameter names and endpoint names.

So before guessing, run:

from gradio_client import Client
client = Client("Wan-AI/Wan2.1-I2V")
client.view_api()

That will show you:

the correct api_name
the exact input order
whether it expects:
  image
  prompt
  negative_prompt
  steps
  seed
  motion
  duration
  etc.

If your script fails, this is usually the reason.

How to write a good prompt for image-to-video

For Wan-style I2V models, prompts work better when they describe motion, not just appearance.

Good prompt style
Strong foreground-background separation, cinematic parallax motion, slow Ken Burns zoom-in, subtle dolly zoom, smooth drone-like camera glide, realistic depth, stable composition, natural lighting

Better if you want less distortion
Subtle camera movement only, light parallax, gentle zoom-in, realistic depth, stable face and body, minimal warping, smooth motion

If you want a more dramatic effect
Dramatic depth parallax, paradox 3D motion, pronounced dolly zoom, sweeping aerial drone move, cinematic camera travel, immersive perspective shift

Recommended settings to start with

If the UI exposes these controls, try:

Duration**: 4 seconds
Steps**: 20–30
Guidance / CFG**: 5–7
Seed**: random at first
Motion strength**: medium
Resolution**: start smaller, then increase once it works

This gives a good balance of:
speed
stability
fewer weird artifacts

Common problems and fixes

1. The video looks warped
Use a softer prompt:

subtle motion, gentle parallax, stable composition, minimal distortion

Also reduce:
motion strength
duration
extreme camera effects

2. Faces deform
Add stability wording:

stable face, minimal facial distortion, smooth natural motion

And avoid too much:
dolly zoom
aggressive 3D parallax
long duration

3. Nothing happens in the video
Increase motion wording:

visible camera push-in, stronger parallax, gentle drone sweep

Also raise:
motion strength
duration slightly

4. The script errors on predict()
That usually means one of these is wrong:

wrong Space ID
wrong api_name
wrong argument order
the app expects more parameters

Run:

client.view_api()

Then match the script to exactly what it shows.
