Finding the Exact API Endpoint

Gradio spaces frequently update their backend function signatures. If the script throws an API error, you can easily inspect the expected variables. Add this quick snippet to your Python environment to see exactly what parameters the Wan2GP space requires:

from gradio_client import Client
client = Client("Wan-AI/Wan2.1-I2V")
client.view_api()

This command will output a map of all valid api_name endpoints (like /predict or /generate) and the exact order of arguments (such as image, prompt, seed, and aspect ratio) you need to pass into the .predict() function.

Understanding Your Prompt Elements

The prompt you provided utilizes advanced cinematic terminology to guide the AI's camera motion. Here is a breakdown of how the AI interprets these specific terms:

Depth & Paradox 3-D**: These terms instruct the model to heavily emphasize the foreground-to-background separation. It forces the AI to create parallax, where objects closer to the camera move faster than objects in the background, creating a convincing three-dimensional illusion from a flat 2D image.
Ken Burns Effect**: A classic documentary technique involving a slow, smooth panning and zooming motion across a still image. It adds a subtle, dramatic narrative feel to the generation.
Dolly Zoom (Vertigo Effect)**: This is an unsettling cinematic effect where the camera moves closer to the subject while simultaneously zooming out (or vice versa). It keeps the subject the same size in the frame while the background drastically warps and changes perspective.
Drone Effect**: Suggests aerial, sweeping, and stabilized camera movements. It tells the model to simulate the smooth, floating motion characteristic of a high-end camera drone tracking a subject.
